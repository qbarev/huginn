# Proposal

## Why

Чтобы начать пользоваться `huginn`, сейчас нужно вручную поставить `uv` и `ffmpeg`, знать команду `uv tool install` с нужными флагами и проверить `PATH`. Нужен один шаг, после которого команда `huginn` работает из любой директории.

## What Changes

- Появляется скрипт `install.sh` в корне репозитория: проверяет платформу, ставит через Homebrew недостающие `uv` и `ffmpeg`, устанавливает команду `huginn`, при необходимости прописывает каталог команды в `PATH` и проверяет, что команда запускается.
- README описывает установку через этот скрипт и запуск без `uv run`.

Вне скоупа: установка самого Homebrew, удаление `huginn`, поддержка платформ кроме Mac с Apple Silicon.

## Capabilities

### New Capabilities
- `installation`: установка `huginn` и его зависимостей на машину пользователя одной командой — проверка платформы, зависимости, команда, `PATH`, проверка результата.

### Modified Capabilities

Нет.

## Impact

- Новые файлы `install.sh` и `tests/test_install.py`; правки README.
- Скрипт вызывает `brew` и `uv` и может дописать строку в конфиг оболочки пользователя (`~/.zshrc`, `~/.bash_profile` или `~/.profile`).
